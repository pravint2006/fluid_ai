// Request Lifecycle //

The 5-Gate Defense Pipeline

GATE 1
Rate Limiter

5 req / 60s sliding window per IP. Blocks DoS floods before parsing.

Drop ➔ 429
GATE 2
Authentication

SHA-256 hash comparison with constant-time HMAC.

Fail ➔ 401
GATE 3
Guardrails

Regex filters + Meta Llama-Guard AI model evaluate safety.

Block ➔ 400
GATE 4
RBAC Check

Restricts employee directory queries to admin users.

Deny ➔ 403
GATE 5
Execution & Log

Executes business action and flushes JSON Lines audit trail.

Pass ➔ 200 OK
🔒 Zero Traceback Disclosure: Global catch-all handler returns generic {"detail": "..."} without echoing user input. FastAPI Async Architecture
